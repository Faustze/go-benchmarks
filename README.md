# go-benchmarks

Замеры производительности Go. Сайт: https://faustze.github.io/go-benchmarks/

| # | Вопрос |
|---|---|
| [001](001-gc-pointers/) | Сколько стоит сборка мусора для кэша на 10 млн записей с указателями и без |

В папке каждого замера:

- `index.html`: страница с графиками и выводами;
- `data.json`: сводка по всем прогонам и каждая сборка из `GODEBUG=gctrace=1`;
- `img/`: картинки для статьи.
